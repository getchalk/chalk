5. ANMERKUNGEN & WEITERE SCHRITTE
--------------------------------------------------------------------------------
1. Der gesamte Code und alle Build-Artefakte sind 1:1 zwischen dem Scratch-Ordner
   und dem Zielordner auf dem Desktop synchronisiert (/Users/user/Desktop/chalk/).
2. Beim ersten Start von Chalk auf macOS wird das System die Berechtigungen für
   Mikrofon und Bildschirmaufnahme über die hinterlegten Info.plist-Texte abfragen.
3. Zur Verifikation der Hardware und optionalen Treiber-Installation steht der Befehl:
   `python src/diagnostics.py --install-loopback`
   zur Verfügung.
4. Das Webportal kann lokal via `./scripts/deploy_web.sh serve` im Browser geöffnet
   oder direkt über GitHub Pages bzw. Cloudflare Pages gehostet werden.
